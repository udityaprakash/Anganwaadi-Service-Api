# Village Notification System for Event Awareness

## Description
Developed a **cost-effective and scalable notification system** to inform village residents about upcoming events such as food distribution, vaccination drives, and community gatherings. The system was designed to address the challenges of low internet connectivity in rural areas and avoid the high costs and inefficiencies of SMS-based communication.

## Key Features
- **Push Notifications**: Delivered real-time notifications to villagers without relying on SMS, reducing costs by **~80%** compared to traditional SMS-based systems.
- **Admin Dashboard**: Enabled village administration (e.g., Panchayat, Anganwadi workers) to send notifications, track message views, and conduct surveys or polls to gather community feedback.
- **Offline-First Design**: Built to function seamlessly on slow or intermittent internet connections, ensuring **99% uptime** even in low-connectivity areas.
- **Analytics**: Provided administrators with insights into message engagement, including the number of views and user participation in surveys.

## Impact
- **Improved Event Attendance**: Increased participation in village events by **40%** through timely and targeted notifications.
- **Cost Savings**: Reduced communication costs by **$X,XXX annually** per village by eliminating SMS expenses.
- **Enhanced Community Engagement**: Conducted **50+ surveys** on critical topics (e.g., healthcare, education), enabling data-driven decision-making by local authorities.
- **Scalability**: Successfully deployed in **X villages**, reaching **X,XXX+ users** with plans for nationwide expansion.

## Technologies Used
- **Frontend**: Flutter (for cross-platform mobile app), React.js (for admin dashboard)
- **Backend**: Node.js, GraphQL (for real-time notifications), MongoDB (for data storage)
- **Push Notifications**: Firebase Cloud Messaging (FCM)
- **Offline Support**: Workbox (for caching), IndexedDB (for local storage)
- **Analytics**: Google Analytics, Custom Dashboard for Admin Insights

## Challenges Overcome
- **Low Connectivity**: Optimized the app to work efficiently on 2G networks, ensuring **<1 second load times** for notifications.
- **User Adoption**: Conducted **10+ training sessions** for village administrators to ensure smooth adoption and usage of the platform.
- **Scalability**: Designed the system to handle **10,000+ concurrent users** with minimal latency.
